## 📌 Ключевые разделы проекта

1. **Барическая загадка и 3D глобус атмосферы**:
   - Интерактивная трехмерная модель Земли (Three.js) с процедурной текстурой континентов, облачными рукавами циклона, изобарами и сферическими волновыми фронтами.
   - Осциллограф микробарографа: сравнение статического приближения ($\Delta P = 0$) и динамического инфразвука ($\Delta P \approx 8.5\text{ Па}$).

2. **Кинематический разрыв (1200 против 50 км/ч)**:
   - Разделение двух физических механизмов: материальной адвекции циклона ($V \approx 40\text{--}60\text{ км/ч}$) и фазовой скорости акустической волны ($c \approx 1200\text{ км/ч}$).
   - Интерактивный калькулятор времени упреждения:
     $$\Delta t = D \cdot \left(\frac{1}{V_{cyclone}} - \frac{1}{c_{sound}}\right)$$
   - Анимированный симулятор гонки фронта и волны давления.

3. **«Голос моря» — Гидроаэродинамический механизм В. В. Шулейкина**:
   - Модель вихревой дорожки Кармана при обтекании ветром морских волн.
   - Расчет частоты излучения по числу Струхаля:
     $$f = St \cdot \frac{v}{h}, \quad St \approx 0.21$$
   - Закон Стокса акустического затухания в вязкой атмосфере:
     $$\alpha = \frac{8\pi^2 \eta f^2}{3 \rho c^3} \implies \alpha \propto f^2$$
   - Интерактивная 2D Canvas гидроакустическая симуляция волн и вихрей со сверхвысокой четкостью (Retina HiDPI).

4. **Биомеханика человека и тест задержки реакции**:
   - Карта резонансных частот органов (брюшная полость 3–5 Гц, сердце 4–6 Гц, альфа-ритмы ЦНС 8–13 Гц, глазные яблоки 18–19 Гц).
   - Интерактивный бенчмарк реакции водителя: замер чистого времени реакции и расчет дополнительного тормозного пути на трассе ($+6.7\text{ м}$ на $100\text{ км/ч}$).

5. **Ловушка открытого окна: Резонатор Гельмгольца**:
   - Моделирование стоячей волны автоколебаний в салоне автомобиля:
     $$f_H = \frac{c}{2\pi} \sqrt{\frac{S}{V_0 \cdot L_{eff}}}$$
   - Расчет уровня звукового давления (до $118\text{ дБ}$).
   - Встроенный психоакустический синтезатор хлопанья воздуха на базе Web Audio API (амплитудная модуляция суббасового тона частотой $f_H$ и фильтрованный розовый шум ветра).

6. **Материалы для защиты доклада**:
   - 3 практических правила безопасности для водителей.
   - Интерактивный аккордеон с исчерпывающими ответами на 4 сложных вопроса экзаменационной комиссии.
   - Интерактивный экзаменатор-тренажер с автоматической проверкой ответов и шкалой готовности.
   - Шпаргалка ключевых формул и стили для печати (`window.print()`).

## 🚀 Развертывание на GitHub Pages

### Вариант 1: Через веб-интерфейс GitHub (2 минуты)
1. Создайте новый репозиторий на [GitHub](https://github.com/new), например `atmosfera` или `baric-storm`.
2. Загрузите файлы `index.html`, `README.md`, `.nojekyll` в репозиторий.
3. Перейдите в **Settings** $\to$ **Pages**.
4. В разделе **Build and deployment** выберите **Source**: `Deploy from a branch`.
5. В выпадающем меню **Branch** выберите `main` и папку `/(root)`, нажмите **Save**.
6. Через 1–2 минуты ваш сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

### Вариант 2: Через Git CLI
```bash
git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
git branch -M main
git push -u origin main
```

## 🛠 Технический стек
- **HTML5 / CSS3 / JavaScript ES6+** — 100% клиентский автономный код
- **Three.js (r128)** — 3D визуализация атмосферы
- **Tailwind CSS** — утилитарный дизайн и типографика
- **Web Audio API** — параметрический синтез низкочастотных звуковых колебаний
- **Lucide Icons** — векторная иконографика
- **GSAP & ScrollTrigger** — плавная динамическая прокрутка и анимации
